# Gym Girls Club — центр питания и материалов

Статический мини-портал материалов курса. Лендинг `fitness-landing` не используется и не изменяется.

## Как открыть

Откройте `index.html` в браузере.

## Что внутри

- каталог из 125 рецептов;
- поиск по названию и ингредиентам;
- фильтры по разделам и отметкам;
- подборки по подтвержденным данным рецептов;
- отметки `избранное`, `приготовлено`, `хочу попробовать`;
- прогресс по рецептам;
- бонусы: замены, соусы, базовая корзина;
- список покупок с сохранением галочек;
- CSV-аудит рецептов.

## Важно

- Фотографии и placeholders под фото не используются.
- Данные пользователя хранятся только в браузере через `localStorage`.
- Аудит КБЖУ является технической проверкой согласованности калорий с БЖУ по формуле 4/9/4. Это не заменяет экспертный пересчет по базе продуктов.

## Основные файлы

- `index.html` — главная страница портала.
- `assets/css/materials.css` — стили портала.
- `assets/js/materials.js` — поиск, фильтры, отметки, корзина.
- `assets/data/recipes.json` — структурированные рецепты и бонусы.
- `reports/recipe-audit.csv` — таблица аудита всех рецептов.
- `scripts/generate_materials_data.py` — генератор данных из исходного HTML.
