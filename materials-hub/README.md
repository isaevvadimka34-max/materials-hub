# Gym Girls Club - центр материалов

Статический мини-портал материалов курса.

## Как открыть

Откройте `index.html` напрямую в браузере или запустите локальный сервер:

```bash
python -m http.server 8788 --bind 127.0.0.1
```

После запуска: `http://127.0.0.1:8788/index.html`.

## Структура

- `index.html` - сборник рецептов.
- `calculator.html` - калькулятор КБЖУ.
- `nutrition-guide.html` - полезные материалы.
- `tracker.html` - трекер программы.
- `body-guide.html` - дополнительный гайд.
- `assets/css/materials.css` - общие стили.
- `assets/js/` - логика страниц.
- `assets/data/recipes-data.js` - данные рецептов для сборника.

## Важно

- Проект не требует сборки.
- Пользовательские отметки хранятся только в браузере через `localStorage`.
- Рабочие отчеты, исходники генерации и временные файлы в финальной папке не хранятся.
